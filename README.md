# おとしもの

場所に曲を置いて、そこを歩いたときに鳴らす。POC。

`index.html` 一枚だけです。ビルド不要、依存パッケージなし。

---

## 公開する

### Vercel

```bash
git init && git add . && git commit -m "init"
gh repo create otoshimono --public --source=. --push
```

Vercel で Import → フレームワークは **Other** → そのまま Deploy。設定項目はありません。

### GitHub Pages

リポジトリの Settings → Pages → Source を `main` / `root` に。数分で `https://<user>.github.io/otoshimono/` が生えます。

> **HTTPS 必須。** 位置情報と音声の自動再生は、暗号化された接続でしか動きません。上のどちらでも HTTPS になるので大丈夫ですが、ローカルで開くときは `file://` ではなく `python3 -m http.server` 経由（`localhost` は例外的に許可される）で。

## 使い方

3 つのモードを下のバーで切り替えます。

| | やること |
|---|---|
| **置く** | 地図をタップして場所を作り、曲を割り当てる。ピンをタップすると編集 |
| **歩く** | GPS を監視して、実際にその場所に入ったら鳴らす |
| **試す** | 地図をタップした位置に「立った」ことにする。外に出ずに動作確認できる |

はじめての人の手順は、**曲を追加 → 地図をタップして置く → 「試す」でピンをタップ**。ここまでで鳴れば設定は正しくできています。

## 知っておくべき制約

**画面を消すと止まります。** ブラウザはバックグラウンドに回った瞬間に位置監視を凍結します。iOS は特に厳格です。散歩するときは、開始してから**画面を点けたままポケットへ**入れてください。Wake Lock API で自動消灯は防いでいますが、手動ロックやアプリ切り替えには勝てません。ここだけはネイティブアプリでないと解決しません。

**GPS は市街地で 20〜50m ずれます。** 半径は 30〜50m を目安に。狭くすると、その前を通っても鳴りません。

**曲は端末から出ません。** IndexedDB にローカル保存されるだけで、サーバーには何も送っていません。逆に言うと、ブラウザのデータを消すと曲も場所も消えます。端末間の同期もありません。

**地図タイルには通信が必要です。** 電波の悪い場所ではタイルが出ませんが、GPS 判定と再生は地図なしでも動きます。

## 仕組み（さわるとき用）

- 位置は `watchPosition`、距離判定は Haversine
- 半径に入ったら発火。**半径の 1.6 倍**まで離れて初めて再発火を許可（境界でのバタつき防止）
- 音は Web Audio の GainNode 経由。iOS では `<audio>` の `volume` が変更できないため、フェードはこちらで行っている
- 音の解禁は「歩く」「試す」を押した瞬間に、その場で同期的に実行している。ここを非同期にすると iOS で鳴らなくなる

## この POC で見たいこと

**検証できる** — 場所と音楽の組み合わせが実際に感情を動かすか。もっと置きたくなるか。最初のセットアップの手間に耐えられるか。

**検証できない** — 「アプリのことを忘れた頃に、不意に」というアンビエントな体験。画面を点けている限り、人は待ち構えてしまいます。

友達に渡すときは、**曲 1 つ・場所 1 つでいいので一緒に置いてあげる**のが確実です。空の地図では何も起きないので、そこで離脱します。
